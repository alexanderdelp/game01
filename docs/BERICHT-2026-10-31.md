## Was du entscheiden oder tun könntest

1. **Online-Server für dauerhaft geteilte Welten und Live-Spiel:** Der Referenz-Server liegt bei
   (`server/sync-server.mjs`, ohne Abhängigkeiten). Er braucht einen öffentlich per HTTPS erreichbaren Host –
   dafür ist ein Konto bei einem Anbieter nötig (z. B. Render, Fly.io, ein kleiner VPS). Ohne Server funktioniert das
   asynchrone Teilen per Link.
2. **Live-Spiel ohne eigenen Server (Option):** Per WebRTC wäre direktes Verbinden möglich, braucht übers Internet aber
   einen STUN-Dienst eines Dritten (z. B. von Google). Ich habe das bewusst nicht ohne deine Zustimmung eingebaut.

## Bekannte Grenzen / Ideen für danach

- Dungeons als besondere Herausforderung für Live-Gruppen.
- Größere Waffen (LPC-Übergrößen-Animationen), weitere Zauber, Fraktions-Questreihen, die die Reichsmacht beeinflussen.
- Die Bildrate wurde nur mit Software-Grafik gemessen (headless); auf echten Geräten mit GPU sollte sie deutlich höher sein.
